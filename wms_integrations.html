Jak zapnout UPS a FedEx

  1. UPS: na developer.ups.com se přihlas firemním UPS účtem → Create Application → produkty Authorization (OAuth), Shipping, Tracking → zkopíruj Client ID a Client Secret.
  2. FedEx: na developer.fedex.com vytvoř projekt s API Ship, Track a připoj číslo účtu → zkopíruj API Key a Secret Key. Pro ostrý provoz FedEx vyžaduje schválení (certifikaci) štítků – pošlou se jim testovací štítky z testovacího prostředí.
  3. Supabase → Edge Functions → Create function prg-carrier → vlož kód ze souboru prg-carrier-01.ts → Deploy. V Secrets přidej UPS_CLIENT_ID, UPS_CLIENT_SECRET, FEDEX_API_KEY, FEDEX_SECRET_KEY.
  4. Tracking: Integrations → Cron → job každou hodinu (0 * * * *) → Supabase Edge Function prg-carrier s tělem {"action":"track"}.
  5. Tady přidej účet (číslo účtu, adresa odesílatele) – nejdřív Testovací. Na detailu výdeje pak v kartě 🚚 Doprava a štítky vyplň adresu a klikni Vytvořit zásilku; štítky se vytisknou na PM45 (štítek dopravce 4×6″, vyzkoušej na 100×150 mm). Ze scanneru: Tisk → Štítek dopravce.
  6. Zásilky mimo EU (celní údaje) zatím zakládej na portálu dopravce.
