Jak zapnout odesílání (jednorázově, cca 10 min)
  1. Založ účet na resend.com, ověř svou doménu (nebo pro test použij výchozí odesílatele) a vytvoř API key.
  2. Supabase → Edge Functions → Create a new function → název prg-notify → vlož kód níže → Deploy.
  3. Edge Functions → Secrets: RESEND_API_KEY = klíč z Resendu, NOTIFY_FROM = např. PRG WMS <wms@vase-domena.cz>.
  4. Database → Webhooks → Create: tabulka notify_queue, událost Insert, typ Supabase Edge Functions → prg-notify.
  5. Přidej tady pravidlo a vyzkoušej (např. dokonči příjem) – zpráva se objeví ve frontě a během pár sekund jako „odesláno“.
// Supabase Edge Function "prg-notify" – odesílá e-maily z tabulky notify_queue přes Resend (https://resend.com) // Nastavení: Supabase → Edge Functions → Create function "prg-notify" → vložit tento kód → Deploy. // Secrets (Edge Functions → Secrets): RESEND_API_KEY = klíč z Resendu, NOTIFY_FROM = "PRG WMS <wms@vase-domena.cz>". // Spouštění: Database → Webhooks → Create: tabulka notify_queue, událost INSERT, typ Supabase Edge Function → prg-notify. import { createClient } from 'npm:@supabase/supabase-js@2'; Deno.serve(async () => { const supa = createClient(Deno.env.get('SUPABASE_URL')!, Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!); const key = Deno.env.get('RESEND_API_KEY'); const from = Deno.env.get('NOTIFY_FROM') ?? 'PRG WMS <onboarding@resend.dev>'; if (!key) return new Response(JSON.stringify({ error: 'RESEND_API_KEY chybí' }), { status: 500 }); const { data: rows, error } = await supa.from('notify_queue').select('*').is('sent_at', null).lt('tries', 5).order('id').limit(50); if (error) return new Response(JSON.stringify({ error: error.message }), { status: 500 }); let sent = 0; for (const r of rows ?? []) { const to = String(r.to_emails).split(/[,;\s]+/).filter(Boolean); const res = await fetch('https://api.resend.com/emails', { method: 'POST', headers: { Authorization: `Bearer ${key}`, 'Content-Type': 'application/json' }, body: JSON.stringify({ from, to, subject: r.subject, text: `${r.body}\n\n—\nPRG Systems (automatická zpráva)` }), }); if (res.ok) { await supa.from('notify_queue').update({ sent_at: new Date().toISOString(), error: null }).eq('id', r.id); sent++; } else { await supa.from('notify_queue').update({ tries: (r.tries ?? 0) + 1, error: (await res.text()).slice(0, 500) }).eq('id', r.id); } } return new Response(JSON.stringify({ sent, waiting: (rows?.length ?? 0) - sent }), { headers: { 'Content-Type': 'application/json' } }); });

🏢 Klientský portál a ochrana dat

  1. V Uživatelích nastav účtu roli Klient a vyber klienta. Po přihlášení uvidí jen klientský portál (zásoby, příjmy, výdeje, teploty – jen čtení).
  2. Aby klient nemohl data jiných klientů vidět ani přes přímé dotazy, spusť v Supabase rls_setup-02.sql (zapne ochranu dat na řádcích). Zaměstnanci fungují dál beze změny. Vrácení: rls_off-01.sql.
  3. Admin si může portál prohlédnout za libovolného klienta (výběr nahoře v portálu).
